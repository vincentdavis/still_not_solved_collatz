3n+1 steps as landings

Landing Form

An odd step is a landing: it arrives at an odd target s from a height x, the number of halvings. The pair (s, x) fixes everything — the source is n = (2xs − 1)/3, the ascent is 2n+1, the descent is s(2x − 1) — and every odd number is the source of exactly one landing. Targets divisible by 3 are never landed on, so they are excluded from every cycle at the outset. This page lays the landings out as a table, follows chains of them backwards, and asks exactly how far exclusion reaches.

1 · The landing table bijection · proved

Rows are odd targets s, columns are heights x. A cell is filled when 2xs ≡ 1 (mod 3), i.e. x odd for s ≡ 2 (mod 3) and x even for s ≡ 1 (mod 3); it shows the source n = (2xs − 1)/3. Every positive odd number appears in exactly one cell (Lemma U on the main page). A source that is itself a multiple of 3 is a dead end going further back: nothing lands on it. Rows s ≡ 0 (mod 3) are empty — no landing has that target. Each row holds at most one source smaller than its target, the height-1 cell (2s − 1)/3, and it exists exactly when s ≡ 2 (mod 3) (Lemma U(d)): a rise into s can be undone in one way or none, a fall into s in infinitely many ways. In the literature this table is Wirsching's back-tracing of the Syracuse map (LNM 1681, Ch. II) — Crandall's odd-to-odd map run backwards, Kaneda's inverse map g_d — with the excluded rows being the vertices removed in the pruned 3x+1 graph of Applegate and Lagarias; the columns are Terras's parity classes. The word "landing" is this project's.

height 1: the source is smaller than the target (a rise) height ≥ 2: the source is larger (a fall) dead source: a multiple of 3, nothing lands on it the one cell whose source is its own target: 1 → 4 → 2 → 1

2 · A cycle in landing coordinates proved

Follow landings backwards from a target s₀: choose a height x₁ (of the parity s₀ allows), the source is s₁ = (2x₁s₀ − 1)/3; choose x₂, get s₂; and so on. A cycle is a chain that returns: sL = s₀. Writing each sᵢ = (2Bᵢs₀ − cᵢ)/3i with Bᵢ = x₁ + … + xᵢ and ci+1 = 2xi+1cᵢ + 3i, the return condition is

s₀·(2B − 3L) = cL

— the cycle equation of the main page (T7), read from the landings. The additive ledger also has a landing form: around a cycle Σᵢ sᵢ·(2xᵢ − 3) = L — each rise (height 1) contributes −s, each fall +s, +5s, +13s, … for heights 2, 3, 4, … — which is Σ(2n+1) = Σ D(n) rewritten, and like it a consequence of closing rather than a test for it. So a height word (x₁, …, xL) has exactly one rational starting point that closes, s₀ = cL/(2B − 3L), and it is a cycle only if that number is a positive odd integer and every intermediate source is an integer coprime to 3. For the word (2): s₀ = 1/(4 − 3) = 1, the loop 1 → 4 → 2 → 1. Type any height word and see where it would have to start.

3 · What exclusion reaches proved · cited

Targets. A multiple of 3 is never landed on: 3n + 1 ≡ 1 (mod 3) and halving does not change that. So no member of a cycle is divisible by 3 (T0), and the empty rows above are exactly the excluded targets.
Sources. The source at height x is a multiple of 3 exactly when 2xs ≡ 1 (mod 9). Since 2 has order 6 mod 9, among the admissible heights (one parity) every third one is dead: for s = 5 the heights 1, 7, 13, … give dead sources 3, 213, …, and 3, 5, 9, 11, … give live ones. So every target coprime to 3 has infinitely many live sources, and backward chains of every length that avoid multiples of 3 — reachability alone excludes the multiples of 3 and nothing else. The residues a cycle's maximum can have are then only pinned mod 9 (M ≡ 2, 8, which is T4); the sieve on the main page saturates there without a size bound (sieve.surviving_residues_mod3_no_size). In numbers: with x₀ the residue mod 6 solving 2x₀ ≡ s−1 (mod 9) — x₀ = 0, 5, 4, 1, 2, 3 for s ≡ 1, 2, 4, 5, 7, 8 (mod 9) — the dead heights are x ≡ x₀ (mod 6) and the live ones x₀ + 2, x₀ + 4; the lowest source is dead exactly for s ≡ 5, 7 (mod 9). The lowest-height cases are Lemma 5.5 and Fig. 5.2 of Monks, Monks, Monks and Monks (2013); the mod-6 periodicity is the one-line extension.
The leaf rule, mod 9 by mod 6

Rows: the target's residue mod 9. Columns: the height mod 6. A cell is admissible when the parity matches; it is dead when 2xs ≡ 1 (mod 9).

The other unconditional exclusion runs forward. A cycle's maximum must also stay a maximum going forward: walking on from M as a source, the odd values must never exceed M. That is a condition on M mod 2a and it kills classes at a = 2 (M ≡ 3 mod 4, T1), a = 4 (9 mod 16, T8), a = 7 (97, 125 mod 128), and so on — but it saturates too, at a limiting density of about 0.2863 of the odd numbers (main page, §4b). Backward, exclusion stops at the multiples of 3; forward, at that 28.6 %.

What a size bound adds. Inside a cycle every member is at most the maximum M, so the backward chain from M must stay below M — and that is a real constraint: with it the survivor set shrinks at every depth (the death-depth sieve, survivor counts 1, 2, 3, 6, 10, 22, 50, … out of 3k; main page). An odd M > 1 with an infinite bounded backward chain is exactly a second cycle, so this is where the exclusion stops being a filter and becomes the problem itself.

4 · The heights are the word cited

The height word of a cycle is its halving word, and the residue bookkeeping of section 2 is a finite automaton: the target's residue mod 3k and the height determine the source's residue mod 3k−1 going back, while going forward n mod 3k and x determine s mod 3k. A cycle's word is a closed walk of that automaton at every depth, which is the statement that the word is live at one residue mod 3k — the residue map Φk of the words chapter on the main page, where the sign law lives. The automaton is definite: after k landings the residue mod 3k depends only on the last k heights, not on where the walk started — Sk(n) ≡ Φk(xk, …, x₁) (mod 3k) for every odd n with those first k heights. Nothing on this page is new; it is the coordinate system in which those results are easiest to see. The write-up with every claim refereed twice is docs/LANDING.md, pinned by tests/test_landing.py.
