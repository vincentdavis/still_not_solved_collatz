Terras, drawn: what n mod 2ᵏ decides

Parity Atlas

Each row is one odd residue class n ≡ r (mod 2k); each column is one step of T(n) = (3n+1)/2 or n/2. Every number in the class takes exactly these first k steps — that is Terras's theorem — and every length-k word that starts with an odd step appears in exactly one row. A rise is an orange single (one halving), a fall is an aqua cell followed by its extra halvings as pale slide cells.

row order

odd step that rises (next value odd again: height 1) odd step that falls (next value even: height ≥ 2) the extra halvings of a fall odd step whose direction lies beyond column k coefficient stopping time: the word alone forces value < start

In 2-adic order rows are sorted by the bits of r from the least significant up, so column j is constant on blocks of 2k−j adjacent rows: the atlas is the binary tree of residues. The top half (r ≡ 1 mod 4) falls first, the bottom half (r ≡ 3 mod 4) rises first — your mod-4 split; the quarters refine it mod 8, and so on. A row's word gives 3t/2j after j steps with t odd steps; the coefficient stopping time is the first j with 3t < 2j. Terras proved the fraction of classes settled by step k tends to 1 — watch the header count grow with k. (Whether the true stopping time always equals the coefficient stopping time is Terras's still-open conjecture.)
