the 3n+1 odd step as a signed distance

Drop Function

For an odd n the next odd number on its trajectory is S(n) = (3n+1)/2x, with x the number of halvings. The drop f(n) = n − S(n) is how far the trajectory has come down by the time it is odd again — negative when it went up. It is the net of the cycle ledger's pairs with the sign flipped, and n − s in the landing form. This page builds the function, says exactly which numbers are drops and how many odd numbers share each one, keeps the drop ledger along a trajectory, and answers the question a cycle raises: combinations of drops that sum to zero exist in abundance, some of them with ends that pass every gate a cycle's largest and smallest members must pass — and none of them is a chain.

1 · The function definition · proved

With x = v₂(3n+1) and s = S(n), the drop is f(n) = n − s = ((2x − 3)·n − 1)/2x. It is always even (two odd numbers). It is negative exactly when x = 1, i.e. n ≡ 3 (mod 4): the step is a rise by (n+1)/2. It is zero only at n = 1. Otherwise x ≥ 2 and the fall is at least (n−1)/4. On each class n ≡ n₀ (mod 2x+1) the function is a straight line of slope 1 − 3/2x: −½, ¼, ⅝, 13⁄16, 29⁄32, … — the halving rays seen from n instead of from s.

2 · Which numbers are drops theorem · proved

Every even integer is a drop, and the sources of a drop are read off the divisors of 3d+1. Write d = f(n), s = S(n), x the height. Then n = s + d and 3n + 1 = 2xs give (2x − 3)·s = 3d + 1. So:

  • d < 0: only x = 1 fits (2 − 3 = −1), s = −3d − 1, one source n = −2d − 1 = 2|d| − 1. Every negative even number is the drop of exactly one odd number, and it is ≡ 3 (mod 4).
  • d = 0: (2x − 3)·s = 1 forces x = 2, s = 1: only n = 1, the fixed point.
  • d > 0: one source for each divisor of 3d + 1 of the form 2x − 3 with x ≥ 2, namely n = d + (3d+1)/(2x − 3) at height x. The divisor 1 (x = 2) always works, so every positive even d has the source 4d + 1; the others come from 5, 13, 29, 61, 125, 253, 509, 1021, … (2x − 3, OEIS A036563; prime for x = 3, 4, 5, 6, 9, 10, 12, 14, 20, 22, 24, 29, …, A050414).
  • odd d: never.
Proof. Both directions are the identity (2x − 3)s = 3d + 1. Given n, put s = S(n), d = n − s. Given a divisor 2x − 3 of 3d+1 with quotient s, the number n = s + d is odd (odd plus even), 3n+1 = 3s + 3d + 1 = 2xs, and s is odd, so v₂(3n+1) = x exactly and S(n) = s. The map x ↦ n is injective because n = d + (3d+1)/(2x − 3) is strictly decreasing in x. ∎

How many odd numbers share a drop

The count is unbounded (proved). The numbers 2x − 3 are odd and prime to 3, so their least common multiple over 2 ≤ x ≤ X has a multiple M ≡ 1 (mod 6), and d = (M − 1)/3 is an even drop with at least X − 1 sources. For X = 7: lcm(1, 5, 13, 29, 61, 125) = 2 874 625 ≡ 1 (mod 6), d = 958 208, six sources — and by the divisor count no smaller drop has six.

The sources at each height

At height x the sources are one class mod 2x+1, the targets one odd class mod 6 (s ≡ 1 for even x, s ≡ 5 for odd x, so 2xs ≡ 1 (mod 3)), and the drops the arithmetic progression d₀ + 2(2x − 3)·k. The first source at an even height is (2x − 1)/3, which lands on 1.

3 · The drop ledger of a trajectory telescoping · proved

Along the odd steps n = n₀ → n₁ → … → 1 the drops telescope: Σ f(nᵢ) = n − 1. So the falls' total exceeds the rises' total by exactly n − 1, whatever the trajectory does in between. The running sum after step i is n − nᵢ₊₁, the height of the start above the current odd number.

4 · Combinations that sum to zero computed · proved

Do combinations of drops that sum to zero exist? Yes, for every size, and it is easy to say why. What does not exist below every bound ever searched is a zero-sum combination that is also a chain — and a zero-sum chain is exactly a cycle.

  • Pairs. For every even d ≥ 2 the rise source 2d − 1 has drop −d and the fall source 4d + 1 has drop +d: {3, 9}, {7, 17}, {11, 25}, … Every zero-sum pair is {2d − 1, one source of d}, so below N there are as many as there are fall sources below N whose drop is at most (N−1)/2: 83 below 400, 2 109 below 10 000.
  • Every size. {3, 7, 11, …, 4k − 5, (2k−1)²}: the first k − 1 rise sources drop by −2, −4, …, −2(k−1), total −k(k−1), and the odd square (2k−1)² ≡ 1 (mod 8) lands at height 2 with drop ((2k−1)² − 1)/4 = k(k−1). Sizes 2, 3, 4: {3, 9}, {3, 7, 25}, {3, 7, 11, 49}.
  • Chains. A set is a chain when its members can be ordered so that each one's target is the next: n₁ → n₂ → … → n_L → n₁. Its drops sum to zero automatically (telescoping), and it is a cycle. The converse fails badly: the sum only constrains the multiset of drops, while a chain fixes every member from the previous one and leaves a single number free, whose closure is the cycle equation. Below 271 the only chain is {1} (Barina 2025), and no cycle with fewer than 92 rise-runs exists at any size (Hercher 2023).
  • No 2-chain (proved). A rise a → b = a + (a+1)/2 followed by a fall back to a means the fall's drop is d = (a+1)/2, so a = 2d − 1, b = 3d − 1, and S(3d − 1) = 2d − 1 requires 9d − 2 = 2x(2d − 1), i.e. d·(2x+1 − 9) = 2x − 2. At x = 2 that is d = −2; for x ≥ 3 it puts d strictly between 0 and 1. No solution — the smallest case of Steiner's 1977 theorem on one-circuit cycles.

With the gates at both ends

A cycle's largest member M and smallest member m must pass tests that involve nothing but the number itself, so they can be imposed on a zero-sum set that is not a chain. Maximum gate, depth D: 3 ∤ M; the first D forward iterates stay ≤ M (depth 1 is M ≡ 1 (mod 4), depth 2 adds M ≢ 9 (mod 16)); and some chain of D predecessors stays ≤ M while avoiding multiples of 3 (depth 1 is M ≡ 2 (mod 3) and M ≢ 5 (mod 9)). This is the sieve of the main page, T0–T4 and T8 at depths 1 and 2. Minimum gate, depth D: 3 ∤ m and the first D forward iterates stay ≥ m, because the whole cycle does (depth 1 is m ≡ 3 (mod 4), Lean-checked; depth 2 adds m ≢ 3 (mod 16) for m > 5). The minimum has no backward half: predecessors above m always exist. In Terras's language the minimum of a second cycle would have infinite stopping time, and the depth-D gate keeps the residue classes that have not stopped after D odd steps.

Among odd numbers below 216 the minimum gate passes 33 % at depth 1, 25 % at depth 2, 13.5 % at depth 4 and 6 % at depth 8; the maximum gate 11 %, 5.6 %, 1.8 % and 0.4 %. The zero-sum sets thin out accordingly and no faster. Below 10 000 the 2 109 pairs become 277, 93, 35, 18 and 7 at depths 1, 2, 3, 4 and 6; below 400 the 4 701 triples become 169, 61, 27, 1 and 0; below 100 the 2 737 quadruples become 124, 9, 0, 0 and 0. Every gated pair is {2d − 1, 4d + 1}: the larger member must be a fall source, and the fall source of d exceeds the rise source 2d − 1 only at height 2. Such pairs exist at every depth tried — the smallest d is 4 at depths 1 and 2, 40 at 3 and 4, 112 at 5 and 6, 592 at 7 and 8, and 128 of them have d below 200 000 at depth 8. Whether some depth finally excludes them all is not settled here; that none of them ever closes into a chain below 271 is Barina's search.

5 · What a cycle would have to balance identity · proved

Around a cycle with members n₁, …, n_L the drops sum to zero, so the rises' ledger equals the falls' ledger: Σrises (n+1)/2 = Σfalls ((2x − 3)·n − 1)/2x. This is one identity in three vocabularies: the ledger page's E = 4·O + 2L, the landing form's Σ sᵢ(2xᵢ − 3) = L, and this one. Each says what the members must add up to, none says which members. The finite version of "which" is what the SAT box decides for one box at a time, the chain closer reads off any list of heights, and the multiplicative ledger turns into the continued fraction of log₂3.

The only odd number with drop 0 is 1, so a cycle other than {1} has no member that lands on itself; its rises and falls must cancel across members. Every odd number outside {1} is either a rise source (≡ 3 mod 4) or falls by at least a quarter of itself.
