The 2-adic skeleton of the Collatz graph, in three axes

Halving Surface

Same axes as the ray chart — x is the number of halvings, the vertical axis is the value y·2x — plus a third: the reduced odd y, the root a number halves down to. Every integer point (x, y·2x, y) lies on the sheet value = y·2x; each ray is a level curve of that sheet at constant depth, and a 3n+1 jump now moves visibly along the depth axis — toward a larger reduced odd (a rise) or a smaller one (a fall).

With the value axis in log₂ the sheet is log₂(value) = x + log₂ y: every ray is a straight line of slope 1, all parallel, and the sheet is the same curve translated along x. All the arithmetic of the Collatz map is in the arrows that hop between those parallel lines. Switch the odd axis to log₂ as well and the sheet becomes a plane. Hover any point for its identity; the pads at height x = 1 are the only ones a jump can rise onto.

A trajectory is a path on the sheet: from an odd base it jumps to a pad, slides down that pad's ray to its base (each halving is one step left along the ray), and jumps again, until it reaches 1. The sheet and axes stretch to the path's reach, so a large start still fits; the odd axis in log₂ keeps the small rays readable beside it.
