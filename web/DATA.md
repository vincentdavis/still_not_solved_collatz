## Read this first

* **Nothing here is new mathematics.** T0/T1/T6/T7 are published (Böhm–Sontacchi
  1978, Crandall 1978, Brox 2000, Kaneda 2015, Eliahou 1993, Simons–de Weger 2005,
  Terras 1976, Tao 2022). T2 is the literature's standard local-maximum analysis.
  T3/T4/T5/T8 are one-line corollaries of folklore that were not found written
  verbatim — the weakest possible form of novelty. Per-claim citations live in
  `theorems[].prior_art`; a viz that renders a claim should render that field too.
* **Three GROUND_TRUTH.md statements are corrected here**, each with a computed
  counterexample in the file: T1 needs no `M > q`; T5 needs `M > 11q/7`, not
  `L ≥ 3`; T4 does *not* "recurse to higher powers of 3" on its own. See
  `theorems[].corrects_ground_truth`.
* **Deep sieve levels are conditional.** A level-`k` exclusion is only valid for
  `M > running_max(k)` in `sieve_layers.floor_rule_thresholds`. Do not paint a
  small number "excluded at level 6" without saying so.

## Notation (also in `meta.notation`)

```
S_q(n) = (3n+q)/2^b,  b = v2(3n+q),  n odd, q odd, 3 ∤ q
cycle:  L odd elements, M = largest odd element, B = total halvings
forward from M:   x_0 = M,  x_j = (3 x_{j-1} + q) / 2^{a_j}
backward from M:  y_0 = M,  3 y_j + q = 2^{b_j} y_{j-1},  B_k = b_1 + … + b_k
                  y_k = (2^{B_k} M − c_k)/3^k,  c_k = 2^{b_k} c_{k-1} + 3^{k-1} q, c_0 = 0
relation:         b_j = a_{L+1−j}   (the backward vector is the reverse of the forward one)
```

### 1. `wheel` — mod-12 sieve

```
n_odds   10000            odd n = 1, 3, …, 19999   (index i ↔ n = 2i+1)
codes    "ca0abaca2ab…"   one char per odd, length n_odds
```

| char | rule | condition | why |
|---|---|---|---|
| `a` | T1 | `n ≡ 3 (mod 4)` | `3n+1 ≡ 2 (mod 4)`, so `v2 = 1` and `S(n) = (3n+1)/2 > n`: **n ascends** |
| `b` | T0 | `3 \| n` | `3y+1` is never `≡ 0 (mod 3)`: **n has no odd predecessor at all** |
| `c` | T2 | `n ≡ 1 (mod 3)` | `(2n−1)/3 ∉ ℤ`; the parity of `b` is forced even, so every odd predecessor `(4n−1)/3, (16n−1)/3, …` **exceeds n** |
| `0`–`9` | — | `n ≡ 5 (mod 12)` | survives; the digit is the deepest 3-adic level it also survives |

Priority when several apply: `a > b > c` (`priority` field). Level 0 = 3-adic
level 1 fails, digits are capped at 9.

> **The wheel's one over-claim.** Rules `a`/`b`/`c` exclude the maximum of a q=1
> cycle with `M > q = 1`, i.e. `n ≥ 3`. Index 0 (`n = 1`) is labelled `c` but `1`
> *is* the maximum of the trivial cycle `{1}` — T2 needs `M > q` strictly, since
> at `M = q` the "predecessor" of `M` is `M` itself. `known_exception_index: 0`
> flags it; a viz should render index 0 specially.

Also: `counts` (`a` 5000, `b` 1666, `c` 1667, `survive` 1667 — exactly 1/6),
`per_mod12` (residue → total + rule), `deep_level_counts`, `survivor_class`
(`{modulus: 12, residues: [5]}`), `legend`, `caveat`.

> **The user's seed observations, honestly.** "7 can't be the largest" is correct
> and is exactly rule `a` (7 ≡ 3 mod 4). The stated reason for excluding 11 —
> "to reach 11 you need a bigger odd" — is **wrong**: 7 → 11 with 7 < 11
> (see `trajectories`). 11 *is* excluded, but by rule `a` (11 ≡ 3 mod 4).

### 2. `backward_tree` — surviving halving-vectors, q = 1, large M

Nodes are backward prefixes `(b_1…b_k)` with `b_j ≥ 1` and
`B_j ≤ ⌊j·log₂3⌋` for every `j ≤ k`. `b_1 = 1` is *forced* by the rule — that is T2
falling out of the size condition.

**Encoding (`child_counts`, `max_depth` = 13).** `child_counts[k-1]` is a digit
string with one digit per depth-`k−1` node, in canonical order, giving its number
of children. A node with prefix sum `B` has exactly the children `b = 1 … ⌊k·log₂3⌋ − B`,
in that order. Root = depth 0, `B_0 = 0`. Reconstruct:

```js
let B = [[0]];                                   // B[k] = prefix sums at depth k
for (const [k1, cs] of data.backward_tree.child_counts.entries()) {
  const k = k1 + 1, next = [], parent = [];
  B[k1].forEach((b, i) => { for (let j = 1; j <= +cs[i]; j++) { next.push(b + j); parent.push(i); } });
  B[k] = next;                                   // drift_k = B[k][i] - k*Math.log2(3)  (≤ 0)
}                                                // ratio 2^{B_k}/3^k = 2^{drift_k}
```

Total 12 448 digits for 13 levels. `depth_stats[k-1]` gives `N`, `cap = ⌊k log₂3⌋`,
`B_min`, `B_max`, `B_hist` (from `B_hist_from`), `drift_min`, `drift_max` — enough
for the drift plot without expanding the tree.

`N_k` — node counts `k = 1…40` by DP: `1, 2, 3, 7, 12, 30, 85, 173, 476, 961, 2652,
8045, 17637, 51033, …` (the doc's `1,2,3,7,12` confirmed).
`growth.lambda` = 2.83951 = `α^α/(α−1)^(α−1)`, `α = log₂3`; `growth.ratios`;
`growth.fit` (empirical `N(k) ≈ 1.235 λ^k k^{−1.51}`).
`sturmian.word` — the first 60 letters of `⌊k lg3⌋ − ⌊(k−1) lg3⌋ ∈ {1,2}`.

### `sieve_layers` — the deeper layers

**`mod3`** — `layers[k]` for `k = 1…10`: `modulus = 3^{k+1}`, `count`,
`density_of_all`, `N_k`, plus explicit `residues` for `k ≤ 6`.
Counts: `2, 4, 6, 13, 22, 50, 123, 254, 620, 1302`.
`k = 1` is exactly T4: `{2, 8} mod 9`, which ⊗ `M ≡ 1 (mod 4)` gives
`M ≡ 17, 29 (mod 36)`.

`mod3.t0_only_saturates` — **the negative headline.** Without the size condition,
T0 alone gives *nothing* past mod 9: the survivor set is always `M ≡ 2, 8 (mod 9)`
lifted, `2·3^{k−1}` of `3^{k+1}`, density 2/9 at every depth. Every further 3-adic
gain comes from T6, not T0. GROUND_TRUTH's "T4 recurses to higher powers of 3"
is misleading.

**`mod2`** — the forward mirror: `x_j ≤ M` for all `j` ⟺ `A_j ≥ ⌈j log₂3⌉`, a
genuine mod-`2^a` condition. `layers[a]` for `a = 2…14`: `count`,
`density_of_odds`, `newly_killed` (when ≤ 10), `residues` for `a ≤ 8`.
Counts `1, 2, 3, 6, 12, 22, 44, 88, 169, 338, 646, 1292, 2584`.
`a = 2` is T1; the first refinement is `a = 4`, killing `{9}` — that is **T8**,
`M ≢ 9 (mod 16)`. `hard_classes` gives `{1,5,13} mod 16` and `{5,17,29} mod 48`.
`limiting_density_among_odds` = **0.286315** — the whole forward 2-adic sieve is
worth 1.804 bits *forever*, then saturates.

**`combined_crt.rows`** — CRT product per `k` (moduli coprime): `modulus_bits`,
`density_among_odds`, `bits_removed`, `one_in`. Best row: `k=10, a=14` →
1 odd in 431, at modulus ≈ 2^31.4. Carries the caveat that the product is a
statement about *residue classes*, and a joint statement about an actual cycle
only when `L ≥ k + j + 1`.

**`floor_rule_thresholds`** — `g[k]` and `running_max[k]`. `g` = the largest `M`
for which T6's exact test still admits a vector the floor rule rejects.
`g(2) = 1` reproduces T5's `M ≥ 2` (sharp ratio `11q/7`); `running_max(13) = 538`.
GROUND_TRUTH's `M ≥ 2^68` is wildly over-conservative.

### 4. `diophantine`

T7 forces `2^B > 3^L`, so `B = ⌊L log₂3⌋ + 1` at best. Writing
`2^B = ∏(3 + q/n_i)` over the cycle and using `min ≤ n_i ≤ M`:

```
excess(L) = 2^{B/L} − 3        cycle minimum ≤ 1/excess(L)        M ≥ 1/excess(L)
```

`rows` — `L = 1…200`, each `{L, B, drift, excess, min_bound}` where
`drift = B − L·log₂3 ∈ (0,1]` and `min_bound = 1/excess`. Computed with 90-digit
`Decimal`, not float64.

`best_in_table` — `L = 200, B = 317, min_bound = 12824`. So **no q=1 cycle of any
length ≤ 200 exists**: its minimum would have to be under ~13 000, and Barina
has verified past `2075·2^60 ≈ 2.39·10^21` — a factor of ~10^17.
`L = 1` gives `min_bound = 1`: the only q=1 fixed point is 1 itself.

`records` (34 entries) — every `L ≤ 20000` setting a new record `min_bound`.
The best, `L = 15601` (`B = 24727`, a convergent), still only permits a minimum of
`2.86·10^8` — ~10^13 below the verified bound. This is *why* the approximation
`B/L → log₂3` has to be astronomically good.

`cf_log2_3` — `terms` = `[1,1,1,2,2,3,1,5,2,23,2,2,1,1]` and `convergents` with
`{a, B, L, ratio, err, from_above}`. Only `from_above: true` convergents
(`2/1, 8/5, 65/41, 485/306, 24727/15601, 125743/79335, 301994/190537`) are
candidate `(B,L)` pairs — those are the record-setters.
`verification_limit` repeats the Barina constant with its source.

### 5. `trajectories`

15 odd-step (Syracuse) trajectories, each:

```json
{"q":1,"start":9,"n":[9,7,11,17,13,5,1,1],"b":[2,1,1,2,3,4,2],
 "ending":"cycle","max":17,"argmax":3,"steps":7,"cycle_enters_at":6,"note":"…"}
```

`n[i+1] = (3*n[i] + q) >> b[i]`. Step `i` **ascends** iff `n[i+1] > n[i]` iff
`2^{b[i]} < 3 + q/n[i]` — for `q = 1`, `n > 1` that is exactly `b[i] == 1`.
`ending` is `"cycle"` or `"cap"` (220-step cap); `cycle_enters_at` is the index
where the repeat begins.

Included: q=1 starts `1, 5, 7, 9, 11, 27, 41, 97, 703, 871`, plus
`q=5/49`, `q=7/5`, `q=17/1`, `q=23/7`, `q=37/53`. Each carries a `note`
naming what it demonstrates — `9 → 7 → 11` is T8 in action (11 > 9, so 9 cannot be
a maximum); `7 → 11` is the counterexample to the user's stated reason for
excluding 11.
